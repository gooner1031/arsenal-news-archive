# 毎日の正式タグ付け（定期タスクの手順書）
対象: 直近24時間（JST）にポストされ、`rv` が付いていないポスト。incoming.json と posts.json の先頭から探す。
まず載せないポストを除く（自動取得の tools/post_rule.py と同じ基準）。載せるのは、引用RP・URL/リンクカード付き・画像/動画付き・【媒体】や（@媒体）の出典表記つきのポストと、それに自分で続けたスレッドの続き。他人へのリプライ、どれにも当たらない一言・私的な発言は incoming.json から削除する（迷ったら残して報告する）。
次に宣伝・告知ポストを除く。`python3 tools/promo.py` で目印（サイトの URL・サイト名・「ホーム画面に追加」・「サイト内のCONTACT」・「指摘」ボタン・「このアカウントで毎日発信」）に当たるポストを一覧し、そのポストは incoming.json / posts.json から削除する（タグは付けない）。目印がなくても、このサイト（アプリ）自体の紹介・使い方・フォローのお願いだけのポストは同じく削除し、ID を `tools/promo_ids.txt` に追記する（次回以降の自動取得でも除外される）。アーセナルの情報が入っているポストは、#アーセナル #COYG やフォローの一言があっても残す。
残りの各ポストの全文を読み、次を決めて、そのポストのオブジェクトに書く。
- `k`: カテゴリ番号の配列（meta.json の cats。最大4個）。否定・過去の発言・仮定の話は「移籍・噂」(0) にしない。プレビュー(19)/レビュー(20)は会見や試合の前後の位置づけで判断。コメント類は インタビュー・コメント(3)。
- `p`: 登場する人物の番号（meta.json の people）。無関係な言及は付けない。
- `c`: クラブの番号（meta.json の clubs）。
- `so`: 出典の番号。【媒体】(@記者ID) が既知の記者なら記者も加える。
- `rv`: 1（確認済みの印）。
未登録の選手・スタッフ・監督・クラブが出てきたら、meta.json の people / clubs の末尾に追加（番号を変えない）し、tools/people.py にも追記する。g は 'アーセナル選手' / '監督・スタッフ' / '他クラブ選手・移籍候補' / '他クラブ監督' / 'OB・レジェンド' / '過去の所属選手' から選ぶ。
その後 `python3 tools/test_promo.py` と `python3 tools/test_tracker.py`（`python3 -m http.server 8766` を起動して）で回帰テストを通し、commit して push する。
