# アカデミーの今季成績（academystats.json）

選手ページ（#academy-N）の「SEASON 2026/27 今季の成績」の元データ。

- 出典：アーセナル公式サイトの U21・U19・U18 試合レポート（`https://www.arsenal.com/news/u21s-report-...` など）の **LINE-UPS** と得点者。
- 公式サイトの利用規約は掲載物の転載・再配布を禁じているため、記事の文章・画像は載せない。誰が先発・途中出場し誰が得点したかという事実だけを、レポートを読んで手で数える。自動取得（スクレイピング）はしない。
- 評価点（レーティング）は載せない。アシストは記事中の書き方が一定でないため数えない。
- 1試合 = `matches` の1行：`d` 日付、`t` チーム（U21/U19/U18）、`c` 大会キー（`comp` を参照）、`o` 相手、`h` ホームなら1、`s` アーセナル側から見たスコア、`st` 先発、`sb` 途中出場、`g` 得点者（1点ごとに1回）、`u` 公式レポートの URL。
- 名前は academy.json の `e`（英語フルネーム）にそろえる。academy.json にいない選手（トップチームの選手など）は入れなくてよい（表示されない）。
- 自殺点（オウンゴール）は `g` に入れない。
- 試合を足したら `asof` を更新する。画面の「◯試合分を集計」は `matches` の件数から自動で出る。
