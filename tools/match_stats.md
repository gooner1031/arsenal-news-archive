# 試合スタッツ（matchstats.json）の手順

試合スタッツの定期タスクが試合後に追加する項目。キーは試合日（JST, `YYYY-MM-DD`）。
選手名は `meta.json` の people の `e`（英語表記）と完全一致させる。未登録の選手は people に追加してから入れる。

| 項目 | 内容 |
|---|---|
| `o` `c` `ha` `sc` `fm` | 相手・大会・H/A・スコア（アーセナル側が先）・フォーメーション |
| `xi` | 先発11人 |
| `subs` | 交代 `{m: 分, on: 入った選手, off: 下がった選手}` |
| `bench` | **ベンチ入りした控え全員**（出場した選手も含む）。サイトは `subs.on` を除いた選手を「ベンチ入り（出場なし）」として表示 |
| `abs` | **欠場者** `[{p: 選手, r: 理由, nt: 補足}]`。`r` は `負傷` / `出場停止` / `コンディション不良` / `その他` のいずれか |
| `absSrc` | 欠場情報の出典（例：「試合前のチームニュース（sportsmole.co.uk）と負傷者リストより」） |
| `goals` `st` `potm` `src` | 得点・スタッツ・POTM・出典ドメイン |

## ベンチ（bench）
- 試合後のラインナップページ（starting11.com の `/fixtures/<home>-vs-<away>-YYYYMMDD`、foxsports.com のボックススコア、ESPN など）から控え全員を取る。
- 確認：`subs` の `on` の選手が全員 `bench` に入っていること、`xi` と重複しないこと。合わなければ入れない。
- Transfermarkt は取得できないので使わない。

## 欠場者（abs）
- **試合時点で確認できたものだけ入れる。推測で埋めない。** 取れなければ `abs` 自体を入れない（サイトには何も出ない）。
- 情報源：試合前のチームニュース（Sports Mole の preview / injury list 記事、クラブ公式の会見など）と、その時点の `profiles.json` の `inj`（毎日の負傷者タスク）。
- 試合中に負傷した選手（例：ニューカッスル戦のラヤ）はその試合の欠場者ではないので入れない。
- ベンチ入りか先発している選手は欠場者に入れない。
- 過去の試合（2026-11-21 より前）は試合時点の負傷者リストが残っていないため、欠場者は空のまま。ベンチは 2026-10-24 以降を補完済み。
